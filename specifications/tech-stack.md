# Stack Tecnológica

## Decisão principal
A equipe prioriza uma stack moderna baseada em TypeScript, com foco em usabilidade, confiabilidade e facilidade de manutenção.

## Tecnologias propostas
- TypeScript
- React
- SQLite
- Estrutura de front-end para site institucional
- HTML, CSS e componentes responsivos

## Justificativa
- TypeScript oferece robustez e produtividade para o desenvolvimento do projeto.
- React permite montar uma interface moderna e escalável.
- SQLite atende ao uso inicial do projeto e à necessidade de armazenar dados simples.
- A combinação é adequada para um site institucional com páginas institucionais, catálogo de cursos e área administrativa básica.

## Requisitos de experiência
- Compatível com navegadores modernos.
- Responsivo para mobile.
- Interface atraente e profissional.
- Estrutura pronta para expansão futura.
